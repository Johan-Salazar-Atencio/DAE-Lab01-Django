# Vault de Documentación · DjangoLab01

Este vault agrupa la documentación del proyecto **DjangoLab01**, una aplicación web desarrollada con **Django 6.1**. El repositorio contiene dos aplicaciones:

- **`sesion1`**: landing page de presentación del laboratorio.
- **`vet`**: aplicación central del Laboratorio 02, que implementa la gestión básica de pacientes (mascotas) de una veterinaria.

## Cómo navegar

- `[[01-investigacion-problematica|01 · Investigación y problemática]]`: contexto de negocio de la veterinaria y el dolor que resuelve la digitalización.
- `[[02-requisitos-funcionales|02 · Requisitos funcionales]]`: lista de requisitos con sus criterios de aceptación.
- `[[03-modelo-datos-paciente|03 · Modelo de datos del paciente]]`: diseño de la entidad Mascota y su implementación en Django.

Los documentos proxy del avance del proyecto (`MEMORIA.md` y `SEGUIMIENTO.md`) los gestionan otros agentes y no forman parte de este índice.

## Ejercicios del Laboratorio 02

1. [[01-investigacion-problematica]] — Investigación de la problemática de una veterinaria y definición del alcance mínimo viable.
2. [[02-requisitos-funcionales]] — Requisitos funcionales del registro de pacientes.
3. [[03-modelo-datos-paciente]] — Modelo de datos de la entidad Mascota y su implementación en Django.
